# Repository scope

This repository documents the Audiobookshelf application, Kubernetes storage,
HTTPS access and operations. Keep content focused on that scope and suitable
for public portfolio review. Do not add credentials, private infrastructure
identifiers, user databases or media files.

Read README.md and docs/ before changes. Be explicit about measured results
versus proposed improvements. These are portable reference manifests, not an
instruction to change the live cluster. Review existing namespace policy and
storage before deploying. Do not overwrite unrelated local work.
